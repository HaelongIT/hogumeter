# CLAUDE.md 편집 규율 — 공식 가이드 요약 + 이 저장소의 승격 경로

> CLAUDE.md는 **매 세션 전문 로드**된다. 여기 적을지 말지는 "지우면 실수하게 되는가"로 정한다.
> 출처: code.claude.com/docs/en/best-practices, /memory (2026-08 확인). 이 파일은 그 재확인 없이
> CLAUDE.md를 고칠 때마다 참고하라고 만든 요약본이다 — 매번 웹 재조회하지 않는다.

## 공식 가이드 핵심

- **권장 길이 60~200줄, 절대 상한 ~300줄.** "매 세션 로드되므로 널리 적용되는 것만 담아라."
- **판정 기준(줄 단위로 적용)**: "이 줄을 지우면 Claude가 실수하게 되는가? 아니면 잘라라."
- **실패 패턴 "The over-specified CLAUDE.md"**: 너무 길면 절반을 무시한다 — 중요한 규칙이 노이즈에 묻힌다.
  Claude가 규칙을 계속 안 지키면 원인은 대개 "규칙이 없어서"가 아니라 "파일이 길어서 못 찾아서"다.
- **포함**: Claude가 못 알아낼 bash 명령 · 기본값과 다른 코드 스타일 · 테스트 지침 · repo 관례(브랜치·PR) ·
  프로젝트 특유 아키텍처 결정 · 개발환경 특이사항 · 비자명한 함정.
- **제외**: 코드 읽으면 알 수 있는 것 · 표준 언어 관례 · 상세 API 문서(링크로 대체) · 자주 바뀌는 정보 ·
  긴 설명/튜토리얼 · 파일별 설명 · 자명한 관행("깨끗한 코드 작성" 류) · **린터/게이트가 이미 강제하는 것**.
- **`@path/to/file` import 문법은 토큰을 안 아낀다** — 매 세션 그대로 로드된다. 순수 조직화용일 뿐
  "온디맨드"가 아니다. 이 저장소는 `@import`를 안 쓴다.
- **가끔만 필요한 도메인 지식은 온디맨드로**: 이 저장소는 `.claude/rules/<scope>.md`(`paths:` frontmatter
  — 매칭 파일을 열 때만 로드, 실측 확인됨)로 이미 구현했다. 공식 Skills(`.claude/skills/`)도 같은 목적.

## 이 저장소의 3계층 승격 경로 (교훈이 나올 때마다 판단)

교훈은 항상 `docs/99-lessons.md`(정본, append-only)에 먼저 쌓인다. **"반복 적용 가능한 규칙"**이 되면
아래 셋 중 정확히 하나로 승격한다 — 절대 CLAUDE.md가 기본값이 아니다:

1. **`CLAUDE.md` `## 축적된 규칙`** — 언어 무관 + 정말 매 세션 필요(그 언어를 안 건드리는 세션에도
   해당). 1~2문장으로 압축. 사례·서사는 넣지 않는다(정본인 `docs/99`가 이미 갖고 있다).
2. **`.claude/rules/<scope>.md`** — 특정 언어/디렉토리에만 해당(core-java·collector-python·web-react·
   shell-scripts). 이 파일들도 "한 줄 규칙만, 전문은 99-lessons" 원칙.
3. **`docs/21-tdd-guidelines.md`** — 테스트 작성 기법·결함 패턴(임계값 경계·분기 커버리지·포트 주입
   검증 등). 온디맨드(그 문서를 열 때만 읽힘), 서사를 좀 더 남겨도 된다.

**판정 순서**: 언어/디렉토리 한정인가? → ②. 테스트 작성 기법인가? → ③. 그 외(범용 방법론·정직성·
계약 원칙)인가? → ①. 애매하면 ①로 넣지 말고 먼저 "정말 매 세션 필요한가"부터 다시 묻는다.

**압축 예시**(3~6문장 문단 → 1~2문장):
> 전: "'값 없음'을 값으로 표현하지 않는다. 스텁·기본값의 sentinel(`0`, `""`)은 스텁 안에 머물지 않고
> 산식·알림·화면까지 흘러 **정상 응답 모양의 거짓말**이 된다(Q-53: 현재가 0 → "100% 싸다"). 불가피하면
> 해석을 **한 곳**에 가두고 그 사실을 보드에 적는다."
> 후: "'값 없음'을 sentinel(`0`, `""`)로 표현하지 않는다 — 하류로 흘러 **정상 응답 모양의 거짓말**이
> 된다(Q-53 전례). 불가피하면 해석을 한 곳에 가두고 보드에 적는다."

## 드리프트 감시

`.claude/hooks/session-brief.sh`가 매 세션 `docs/99-lessons.md` 교훈 수와 위 3곳(①+②+③) 승격 규칙 수를
비교해 보여준다 — 승격이 밀리면(교훈만 쌓이고 규칙화가 안 되면) 그 세션에서 눈에 보인다. 반대로 ①(`##
축적된 규칙`)만 늘어나고 ②③이 안 늘면 "관성적으로 다 CLAUDE.md에 인라인 승격하고 있다"는 신호 — 판정
순서를 다시 밟는다.
